# 3D Modeller (`.glb` / `.gltf`)

Bu klasöre `robot.glb` dosyasını yerleştirdiğinizde uygulama otomatik olarak bu 3D modeli yükler ve mevcut ışıklandırma/scroll sahnesine entegre eder.

Dosya bulunmadığında uygulama, PBR materyallerle (anodize alüminyum, karbon fiber, mekanum tekerlekler, hareketli robot kolu ve okunabilir teknik arka plaka) prosedürel olarak üretilmiş yüksek detaylı FTC/FRC yarışma robotunu kullanır.
